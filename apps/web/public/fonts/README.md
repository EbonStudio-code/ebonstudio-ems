# Ebon Studio web typography

Downloaded 1 November 2026. These are unmodified variable WOFF2 subsets served by Google Fonts, hosted locally by this app. Browsers do not contact Google to render the interface.

| Family | Use | Weights | License |
| --- | --- | --- | --- |
| Space Grotesk | Headings, section titles and summary figures | 400–700 | SIL Open Font License 1.1, `OFL-Space-Grotesk.txt` |
| Plus Jakarta Sans | Body copy, navigation, controls and table content | 400–800 | SIL Open Font License 1.1, `OFL-Plus-Jakarta-Sans.txt` |

The Latin subset is preloaded for each family. Latin Extended is requested only when its character range is needed (including the rupee symbol). Other scripts use the system fallback stack.
